# Nex V1

Nex V1 is a local-first AI chatbot Android app designed to run completely offline.  
It focuses on privacy, performance, and simplicity by running a lightweight language model directly on the device.

---

## Features

- Offline AI (no internet required)
- Chat-based interface
- Fully local data storage (no cloud)
- Fast response with lightweight models
- Minimal, clean UI using Material Design

---

## Tech Stack

- Platform: Android (Native)
- Language: Java
- UI: Material Components
- Model Engine: llama.cpp (planned)
- Model Format: GGUF
- Database: Local (Room / SQLite - planned)

---

## Current Status

Nex is built as a personal AI assistant that:
